### 話者の描き分け

| 話者 | 位置 | 面 | 形 |
|---|---|---|---|
| あなた | 右 | 緑（面） | 角丸 14px、右上を 4px に落とす |
| 具体 | 左 | 面（暖） | 角丸 14px、左上を 4px に落とす |
| 抽象 | 左 | 面（寒） | 角丸 14px、1px の罫を回す |

暖が具体、寒が抽象。
`bg-amber-50` / `bg-sky-50` が持っていた温度の対応を引き継いだもので、ダークでは面（暖）・面（寒）の二組目へ移る。

人間の発話の面は淡い緑に留める。
ダークでは地が暗い分だけ落差が開くので、面をより暗い側（`#263320`）へ寄せて文字色は通常のまま置く。

## 書体と字組み

**和文が本体である。**

| 役 | 書体 | 用途 |
|---|---|---|
| 見出し | 明朝（`Shippori Mincho`） | 問いの本文、画面の見出し |
| 本文・UI | ゴシック（`Zen Kaku Gothic New`） | 発話、ラベル、ボタン、メタ情報 |
| 欧文・数字 | 上の二つの従属欧文 | 和文に混ざる英字と数字 |

画面に出る欧文は日付・`status` の値・数字だけなので、従属欧文で足りる。

| 要素 | モバイル | デスクトップ |
|---|---|---|
| 問い（見出し） | 20px / 行間 1.75 | 24px / 行間 1.7 |
| 発話の本文 | 16px / 行間 1.95 | 17px / 行間 1.95 |
| 入力欄 | 16px | 16px |
| 補助の文・操作 | 14px / 行間 1.7 | 14px / 行間 1.7 |
| ラベル・メタ | 12px / 行間 1.7 | 12px / 行間 1.7 |
| 状態のピル | 12px | 12px |

補助の文・操作は、画面間のリンク・見出しに添える副題・引用・空状態の文言・ボタンのラベル。
ラベル・メタは、話者名・日時・原型・セッションの切り替え。

表が 1.7 前後で締めているのは見出しと短い文字列で、どれも読み下すのでなく拾い読みするため、本文と同じ行間を敷くと塊として読めなくなる。

## 重心 — 読みの器と、書きの間

入力へ触れているあいだ、対話は不透明度 .28 まで退き、入力が面と縁を得て主役になる。

## 状態の見せ方

### `status`（7 値）

淡いピルで出す。
地は 7 値とも一律（面（高））で、先頭の点だけが二値を持つ。

| 点 | 意味 | 値 |
|---|---|---|
| 緑 | 開いている | `new` `stocked` `holding` `permanent` |
| 無彩 | 閉じた | `resolved` `exported` `discarded` |

ラベルの文字列は `VISION.md`「語彙」節が正で、実装の対応は `web/src/lib/question.ts`。

### セッションの区切り

**#57（再訪とセッションの設計）で決着している。**
本文書は選び直さない。

痕跡はキーワードを 3 語まで、日付の脇に小さく添える。

## 動き

AI の応答は、不透明度 0→1 と 7px の落差を 0.85s、行ごとに 0.34s ずらして置く。

ストリーミングは入らない（ADR-0026）ので、一息に届いた本文をこの間隔で置いていく形が現況の最終形になる。

逆引きの着地（`data-landed`、2.5s）は現行のまま残す。

## 部品の型

共通部品は `web/src/components/ui/` にある。

| 部品 | 何を持つか |
|---|---|
| `Button` | 実（緑の塗り）と淡（罫だけ）の二態 |
| `Field` | 入力欄。読みの一行と、書きの間の二態 |
| `Row` | 一覧の一行。問い・メモに共通 |
| `Pill` | 状態のピル。点の二値を持つ |

## 残す摩擦

| 残す（仕様） | 直す（妨害） |
|---|---|
| AI の応答待ち 15〜27 秒 | 何が起きたか分からない沈黙 |
| 二体が必ず両方喋る | 途中で失敗して欠けた turn が残る（#119） |
| 過去のセッションへ発話できない | 呼び出しに上限時間が無い（#120） |
| 一覧に検索も絞り込みも無い | 選択のたびに発話の数だけ再計算が走る（#129） |
| 通知が無い | 選択箇所から目が離れるメモの入力欄（#161） |
| 「答えを出す」ボタンが無い | 実機で入力が引っかかる |

左の列を削らない理由は `extensions/fermentation-and-outlets.md`「設計上の自己言及: 反快適性」。
