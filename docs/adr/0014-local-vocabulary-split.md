# 0014. 手元の環境に固有の語彙と接続を、追跡しない CLAUDE.local.md へ分離する

- **状態**: 採用
- **決定日**: 2026-08-29
- **関係する ADR**: なし

## 文脈

このリポジトリの文書は、作者が手元で運用している個人の知識管理の生態系（vivarium）と接続した状態で書かれてきた。
「器」「膜」「台帳」「正典」「fermentary」といった語彙と、`~/vivarium/...` への参照は、その生態系の中に置かれて初めて意味を持つ。
リポジトリは既に public なので、GitHub から読む人にはこれらが解けないノイズとして漏れている（issue #99）。

制約が三つある。
接続の指示そのものは手元のセッションに必要で、消すのではなく置き場を移すしかない。
`docs/adr/` の記録は追記のみの規約で、本文を一字も削れない。
`CODING.md` や `.claude/skills/coding-standards/` などの一部は複数リポジトリで内容を揃える配布物で、直すなら配布元から配り直す。

## 決定

- 手元の生態系との接続は、リポジトリのルートに置く `CLAUDE.local.md` 一枚へ集め、`.gitignore` で追跡から外す。
  Claude Code は `CLAUDE.md` の後に同じディレクトリの `CLAUDE.local.md` を自動で読むので、`CLAUDE.md` 側に参照の一行は置かない（`@` import は import 行そのものが公開される）。
- `NEXT.md` も追跡から外す。
  中身は手元の申し送りで、公開しても外の読み手に効かず、並列作業でコンフリクトの発生源になる。
- 追跡されている文書とコードの該当語彙は、素直な語（リポジトリ・アプリ・モジュール・置き場・正）へ言い換えるか、「手元の個人知識基盤」へ一般化する。
  配布物の言い換えは配布元で行われたもの（配布元コミット 9852163）を差分適用で取り込む。
- **例外は二つ**。
  `docs/adr/` の既存レコード（0001〜0013 の本文と、タイトルを引き写す `README.md` の索引行）は追記のみの規約が優先し、言い換えない。
  配布元がまだ言い換えていない配布物の箇所（`docs/adr/README.md` 冒頭の一行）は、配布元で直してから配り直すのを待つ。

## 理由

**痕跡ゼロを選び、`@` import を採らなかった条件**: import 行が公開ファイルに残ると、ローカル層の存在自体が外へ漏れる。
参照なしでも自動で読まれることは公式ドキュメントの記載と先行リポジトリでの実測で確認済みなので、痕跡を残す理由が無い。

**ADR の本文を書き換えなかった条件**: 追記のみの規約は「経緯を安全に捨てられる」ことの担保で、例外を作ると過去の記録が現在の都合で動く前例になる。
先行リポジトリ（coten-atlas）は public 化の前だったので一回限りの例外として本文を書き換えたが、このリポジトリは既に public で、同じ語彙が git 履歴にも残っている。
本文だけ直しても履歴からは消えないので、規約を曲げて得られるものが釣り合わない。

**公開向けの用語集を採らなかった条件**: 「消す」でなく「解けるようにする」案は、残る語彙が ADR の過去記録だけになったので見送った。
過去の記録を読む人は経緯を掘る人で、その文脈なら語彙の出自も一緒に掘れる。

## 帰結

- 追跡されているファイルで該当語彙が残るのは `docs/adr/` 配下だけになった
- `CLAUDE.local.md` と `NEXT.md` は clone に含まれない。
  別マシンへ clone すると手元の接続の指示は丸ごと欠け、欠けたことを検出する口も無い。
  これは痕跡ゼロと引き換えに受け入れた代償
- ローカル層はリモート（Claude Code on the web）のセッションから到達できないので、その改定は手元のセッション限定になる
- このリポジトリを追跡していた手元の環境では、この変更を pull した時点で `NEXT.md` が作業ツリーから消える。
  最後の追跡版は履歴に残っているので、そこから復元する

## 覆る条件

- ADR の過去記録に残した語彙が実害（外部の読み手からの混乱など）を生んだら、用語集の案に戻って決め直す
