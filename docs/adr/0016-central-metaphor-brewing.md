# 0016. 中心メタファーをコンポスターから醸造（発酵槽）へ移す

- **状態**: 採用
- **決定日**: 2026-08-30
- **関係する ADR**: 0017

## 文脈

コンポスターは雑多な有機物を投げ込み、微生物に任せて堆肥にする装置で、**投入したあと人間は関与しない**。
実際のトイットは、問いを一つ入れ、培地を整え、二体と議論し、仮答えか次の問いへ蒸留する。
入れる物も、人間の関与の度合いも、出てくる物も違う。

比喩がずれたまま画面の語彙を決めると、言葉が一つずつ実際の動きから外れる。
そして #67（DESIGN.md）が画面の見た目を決める段に入るので、**語彙が先に確定していないと見た目の判断が語に引きずられる**。

棚卸しの結果、比喩語は追跡ファイル 17 件・74 箇所にある（発酵 31・コンポスター 16・培地 16・蒸留 6・攪拌 2・熟成 2・堆肥 1）。
このうち発酵・培地・蒸留・攪拌・熟成は醸造の語彙としてそのまま成立し、実際の工程とも合っている。
**ずれているのは器の選び方だけ**だった。

## 決定

中心メタファーを**醸造 / 発酵槽**にする。

- 器は「問いの発酵槽」（「問いのコンポスター」を置き換える）
- 投入のアクション名は「仕込む」。
  ただし placeholder の「問いをポイっと」は残し、工程名と手触りを別の層に分ける
- 発酵・培地・攪拌・蒸留・熟成は動かさない
- 語彙の正は `VISION.md`「語彙」節。
  工程・画面のアクション名・`status` ラベルがそこから引ける
- 中立な語（発話する・メモ・再訪）は語彙表に醸造側の候補まで載せ、画面へ出すかは #67 で実画面を見ながら決める
- `status` の値には比喩を持たせない。
  比喩は選び直しうるが enum の変更は migration を伴うので、変わる側を表示層へ閉じる（決定の本体は 0017）

## 理由

**捨てるべきものが器だけだと、棚卸しが示した。**
発酵の語彙は既に各所へ入っており、しかも実地の工程（材料を寄せる・議論する・仮答えへ落とす）と対応が付いている。
発酵槽は人間が中を覗き、温度を見て、攪拌する装置なので、**関与するという事実が器の名前の側から支えられる**。

採らなかった案と、それを採らなかった条件。

- **コンポスターを残し工程名だけ言い換える**。
  触るファイルは最小（文書 1〜3・コード 0〜1）で、`status` の enum も動かない。
  採らなかったのは、**ずれているのが工程名でなく器の選び方**だからで、器を残すと「投げ入れたあと関与しない」という含意がそのまま残る。
  比喩の維持コストが実装コストを上回る形になる
- **比喩を捨てて工程名で呼ぶ**。
  嘘はつかない。
  採らなかったのは、投げ入れる気軽さが失われるからで、これは飾りでなく VISION の「ポイっと」——問いを投げるときの心理的な敷居を下げる——が拠って立つところである。
  74 箇所を全廃する幅も、得るものに対して大きい
- **ノート / 日記へ寄せる**（2026-08-29 に人間から出た案。「ノートに言葉を書く」「書籍を読んで著者と対話する」）。
  「AI は答えを与えない」は会話の比喩だと守りにくいが（喋る相手は答えるものである）、**本の著者は答えない**。
  だから VISION との噛み合わせは案の中で最もよい。
  採らなかった条件は二つある。
  一つは、**二体が同じノートへどう書くのかが未決**であること（対等に二人か、片方が余白の書き込みか）。
  ここが決まらないと工程の呼び名が決まらないので、決定 1 を決めても決定 2 へ進めない。
  もう一つは、`ARCHITECTURE.md`「二対一の対話（超相対性理論モデル）」という**構成の下敷きごと動く**こと。
  比喩を替える判断と、対話の構成を替える判断が同じ変更に同居する。
  下敷きの問い直しが決着したときに比喩をもう一度問えるので、この二つは醸造への移行と排他ではない

## 帰結

- `VISION.md` の「中心メタファー」節が書き直され、語彙表を持つ「語彙」節が新設される
- `ARCHITECTURE.md` / `README.md` / `HARNESS.md` / `CLAUDE.md` / `ROADMAP.md` / `extensions/` の比喩語が追随する
- **コードは動かない**（画面の文言・enum・シードは別の変更で運ぶ）。
  語彙が決まる前に画面を触ると、決め直すたびに差分が散る
- `status` の 6 値を一般語へ組み直す migration は #125 が運ぶ（0017 の帰結）。
  触るのは 8 ファイル + migration 1 本
- #67（DESIGN.md）は、この語彙表を入力として画面の語を決める

## 覆る条件

- **二体の置き方が決まり、日記の比喩が工程まで通ると分かったとき**。
  上で採らなかった条件がそこにあるので、条件が消えれば案は生き返る
- 常用の中で「発酵槽」が実際の動きから外れていると人間が判定したとき。
  この issue（#61）が置いた人間の判定トラックがそれで、合わない語が残るなら比喩の選び直しに戻る
