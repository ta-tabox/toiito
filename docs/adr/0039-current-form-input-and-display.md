# 0039. 問いの言い直しは対話画面の見出しで人間が書き、履歴は対話画面に並べ、`/memos` も問いの文を `questionText()` で出す

- **状態**: 採用
- **決定日**: 2026-09-14
- **関係する ADR**: 0040

## 文脈

問いの原型は `questions.body` が持ち、言い直しは現在の形として原型と別に持つ（持ち方は 0040）。
表示する文は `questionText()`（`web/src/lib/db.ts`）が、現在の形があればそれを、無ければ原型を返す。

言い直しを書き込む repo 関数（`setCurrentForm`）を呼ぶのは開発用シードとテストだけで、アプリから言い直しを入力する手段が無い。
常用の中で、人間は問いを言い直したくなった瞬間を持った。

問いの文を出す画面のうち、一覧（`/`）と対話画面（`/q/[id]`）は `questionText()` を出し、`/memos` の行と拡大表示は `question_body`（原型）を出している。
言い直しを入力できるようになると、同じ問いが画面によって別の文で出る。

決めるのは次の三つである。

- 言い直しをどこで入力するか（対話画面の見出しの編集・発話からの抜き出し・AI の提案）
- 言い直しの履歴を画面に出すか
- `/memos` が出す問いの文を、言い直しが入った後にどうするか

## 決定

| 項目 | 決めたこと |
|---|---|
| 入力する場所 | 対話画面の問いの見出し。見出しに触れると入力欄になり、人間が文を書く |
| 空にして保存したとき | 現在の形が無くなり、表示は原型へ戻る |
| 発話からの抜き出し | 作らない |
| AI の言い直し案 | 作らない |
| 言い直しの履歴 | 対話画面で、見出しの下の「原型（不変）」の行と並べ、原型と同じ弱い文字で出す |
| `/memos` の行と拡大表示が出す問いの文 | `questionText()` の結果（現在の形、無ければ原型） |

## 理由

- 言い直す対象は見出しに出ている問いの文なので、入力は見出しそのものを編集する形にする
- `.claude/rules/design.md`「重心」は常設の入力欄を置かず、触れたときだけ書く状態へ移る形を既定にしているので、見出しは触れたときだけ入力欄になる
- 二体の AI が言い直し案を出すと問いを掘る作業の一部を AI が代わりに行うことになり、`docs/VISION.md`「AI の役割」の「掘るのは人間」と衝突するので、AI の提案は作らない
- 発話の文字選択は既にメモの作成に使っており、同じ選択に行き先を二つ持たせると選ぶたびにどちらへ送るかを決める手順が増えるので、抜き出しは作らない
- 対話画面は既に原型を見出しの下に添えて、問いが元の形からどこへ移ったかを読ませているので、途中の形も同じ場所に並べる
- 一覧と対話画面が `questionText()` を出しているので、`/memos` も同じ関数で出して、同じ問いを画面ごとに別の文で出さない
- 原型と履歴は対話画面で確かめられるので、`/memos` には並べない

採らなかった案と、それを採らなかった条件。

- **発話からの抜き出し**。
  言い直しの文を対話の中の発話から取れる。
  メモと同じ選択操作に行き先が二つできるので採らなかった
- **AI の提案**。
  人間が文を一から書かずに済む。
  掘る作業を AI が代わるので採らなかった
- **履歴を画面に出さない**（DB にだけ残す）。
  対話画面の見出しの下が増えない。
  問いが元の形からどこへ移ったかを、原型と最新の形の二点でしか読めなくなるので採らなかった
- **`/memos` は原型のまま**。
  言い直す前の問いの文が出る。
  同じ問いが一覧・対話画面と `/memos` で別の文になるので採らなかった
- **`/memos` に現在の形と原型を並べる**。
  両方を `/memos` だけで読める。
  言い直した問いの行だけが 1 行増え、原型は対話画面で確かめられるので採らなかった

## 帰結

- 見出しの編集は対話の外で言い直しを起こし、0034 が言い直しの履歴を持たなかった条件に当たるので、言い直しの持ち方は 0040 が決め直した
- 見出しの編集と履歴の表示は #241（対話画面の見出しから問いを言い直し、履歴を並べる）が作る
- `/memos` の切り替えは #242（`/memos` が出す問いの文を `questionText()` に揃える）が作る。
  `listMemosWithContext` の戻り値（`MemoWithContext`）が、原型に加えて現在の形を持つ
- #241 と #242 は、履歴の表を入れる #240 の後に作る

## 覆る条件

- 見出しで言い直そうとして、書きたい文が対話の中の発話に既にある回が繰り返されたとき。
  発話からの抜き出しを作るかを決め直す
- `/memos` で、メモを付けた当時の問いの文が分からないために逆引きを誤る回が出たとき。
  `/memos` に原型や履歴を並べるかを決め直す
- 言い直したい文を一から書けず、見出しの入力欄を開いたまま閉じる回が繰り返されたとき。
  AI の提案を作るかを、`docs/VISION.md`「AI の役割」と照らして決め直す
