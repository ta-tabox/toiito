# セッションが一往復の二体のペルソナを、版でなくペルソナで指す

- **状態**: 採用
- **決定日**: 2026-11-02
- **関係する ADR**: 20260915-persona-as-records

## 文脈

#64（二体のペルソナをセッション単位で設定できるようにする）は、セッションごとに一往復の二体を選べるようにする。
20260915-persona-as-records はペルソナと版の表を決めたが、セッションの選択の保存先と、選択が何を指すかを決めていない。
選択を指す先によって、対話の途中でペルソナを編集したときに、次の一往復が編集後の設定で話すかどうかが変わる。
人数と発話の順序を可変にするのは #8（発話周期の可変化）の担当で、それまでは二体に限る。

## 決定

1. **セッションは、一往復の 1 番手と 2 番手のペルソナを、セッションの行の二つの列で指す。**
   決定時点の例は `sessions.first_persona_id` と `sessions.second_persona_id` で、現況は `web/prisma/schema.prisma` が持つ。
2. **選択は版でなくペルソナを指し、一往復のたびにそのペルソナの最新の版で話す。**
3. **二つの列は NULL を許さず、選ばれたペルソナは削除できない。**
   選択を省いたセッションと、選択の列を足す前からあるセッションは、既定の二体を指す。
4. **選べるのは、セッションの持ち主に見えるペルソナ（持ち主のペルソナと既定のペルソナ）だけにする。**

| 対話の途中でペルソナを編集した後 | 振る舞い |
|---|---|
| 次の一往復 | 編集後の版で話す |
| それまでの発話 | 発話を書いた時点の版を指し続ける |

## 理由

- 発話が話した時点の版を指すので、選択がペルソナを指しても過去の発話の呼び名と全文は動かない
- 対話の途中で話し方を調整したい利用者は、セッションを作り直さずに次の一往復から効かせられる
- 一往復の二体が欠けたセッションを、列の NOT NULL が作らせない

採らなかった案:

- **選択が版を指す**: 編集を効かせるにはセッションを作り直すか選択を書き換えることになり、編集と選択の更新が二つの操作に割れる。セッションの中で版を固定したい要求が出たら採る
- **セッションとペルソナを結ぶ別表に、順番と一緒に持つ**: 人数を可変にする #8 の形で、二体に限る間は欠けた順番を DB が拒否できない
- **選択を問いに持たせる**: 再訪のたびに別の二体と話す使い方ができなくなる

## 帰結

- 一往復の手順は、セッションの選択から二体の最新の版を取得してから呼ぶ
- 問いの投入と再訪で二体を選べるようになり、省くと既定の二体になる
- 選択の列を足す migration は、セッションがあるのに既定の二体のペルソナが無い DB で、既定の二体のペルソナの行を作ってから既存のセッションに当てる

## 覆る条件

- #8 で一往復の人数か発話の順序を可変にするとき（選択を別表へ移す）
- セッションの中で話し方を固定したい要求が出て、選択が版を指す方が合うと分かったとき
