# 0050. 一回の付与は論点ごとに立場の違う材料を対にし、外部材料は検索結果の URL を出典に持ち、件数・対・出典を検査して通らない付与を保存しない

- **状態**: 採用
- **決定日**: 2026-09-15
- **関係する ADR**: 0021, 0035, 0038, 0043, 0049

## 文脈

この ADR で培地は、問いに付随する材料（AI が対話の前に集める、外部の調査の結果など）を指す。
構想は `extensions/fermentation-and-outlets.md`「D. 培地（culture）」節が持ち、実装は #63（培地を整える）とその子 issue が持つ。

構想は培地を三種に分けた。

| 種 | 構想が置いた規律 |
|---|---|
| 内部交差 | 自分の過去の問いとメモに、関係する理由を一行添える |
| 外部 | 最大 5 件・出典 URL 必須・対立を必ず含む |
| 異種同型の芽 | 断定しない |

0035 は、「答えを与えない」の実体を「一方向に閉じた材料を出さない」と決め、対立・出典・一度に最大 3 件・未検証の明示の 4 項を規律にした。
0035 の帰結は、培地の外部材料も同じ形で設計すると書いている。
構想の 5 件と 0035 の 3 件は食い違っている。

外部材料をモデルの知識だけで書かせると、出典の URL はモデルの出力にしか由来しない。
0043 は、AI の送信の契約にサーバー側のツールを含め、検索結果を応答で受け取れるようにした。

決めるのは次の四つである。

- 外部材料をどこから得るか
- 一回の付与をどういう構造で出すか
- 外部材料の件数の上限
- 規律に反する付与をどう扱うか

## 決定

### 出所

1. **外部材料は、付与の呼び出しの中で AI が行う web 検索の結果から作る。**
2. **外部材料の出典は、同じ呼び出しの検索結果に含まれた URL に限る。**
   モデルが本文に書いた URL は、同じ呼び出しの検索結果に無ければ出典として扱わない。

### 構造

3. **一回の付与は一つ以上の論点からなり、各論点は立場の違う材料を 2 件以上持つ。**
   材料は一件ごとに出典の URL を一本持つ。

### 件数

4. **外部材料は、一回の付与につき最大 3 件にする。**

### 検査

5. **付与の結果を保存する前に、次の三つを機械で検査する。**

| 検査 | 通る条件 |
|---|---|
| 件数 | 外部材料が 3 件以下 |
| 対 | どの論点も材料を 2 件以上持つ |
| 出典 | どの材料の URL も、同じ呼び出しの検索結果に含まれる |

6. **三つのどれかに通らない付与は、一件も保存しない。**
   通る材料だけを抜き出して保存することもしない。
   利用者への伝え方は 0049 決定 4 に従う。
7. **検査は AI の応答に依らない計算として持ち、プロンプトへの指示だけに任せない。**

決定時点の例として、検索結果は Anthropic の web 検索ツールの結果のブロックが持つ URL である。
現況は `web/src/lib/ai/anthropic.ts` が持つ。

## 理由

### 出所

- **web 検索の結果から作る**: 「問いに対して事前に情報を集める」という要求は、モデルの学習時点より後の情報を含む。
- **検索結果の URL に限る**: 出典が実在のページを指すことを、同じ応答に含まれる検索結果との照合で機械が確かめられる。
- **出典を持たせる目的に合う**: ペルソナ両体の材料の供給規律は、出典を添える理由を、人間が自分で検証に行ける状態を残すためと書いている。

採らなかった案と、それを採らなかった条件。

- **モデルの知識だけで書かせる**: 送信の形を変えずに済む。
  出典の URL が実在するかを検査できないので採らなかった。
- **利用者が貼る URL と文章から作る**: 検索の料金が要らない。
  材料を集める手間が利用者に残り、「対話の前に AI が材料を集める」にならないので採らなかった。
- **既存の問いとメモから作る（内部交差）**: 外部のツールが要らない。
  外部の材料を集めるという要求を満たさないので、外部材料の出所としては採らなかった。

### 構造

- **論点ごとに対にする**: 「対立を必ず添える」のうち、論点ごとに材料が 2 件以上あることを機械で検査できる。
  材料の立場が実際に違うかは件数から分からないので、人間の判定に残る。
- **一件だけ読んでも結論に見えない**: 同じ論点の反対の立場の材料が隣に並ぶ。

採らなかった案と、それを採らなかった条件。

- **平らな一覧にし、全体で対立の組を 1 組以上含むことだけを検査する**: 構造が単純になる。
  一件だけ読むと一方向に閉じた材料に見える行が残り、どの材料とどの材料を並べて読むかを構造が示さないので採らなかった。
- **要約を持たず、検索結果の引用と URL だけを並べる**: 断定の形を検査する必要が無くなる。
  引用は検索結果の短い抜粋（決定時点の Anthropic の web 検索では最大 150 字）で、論点の立場が読めないことがあるので採らなかった。

### 件数

- **0035 と同じ 3 件にする**: 同じ規律の上限が、培地と対話で二つに割れない。
- **並べすぎない**: ペルソナ両体の規律は、並べすぎると人間の判断が材料の量に押されると書いている。

採らなかった案と、それを採らなかった条件。

- **5 件（構想の数）**: 一回の付与で論点を二つ持てる。
  0035 の 3 件と食い違い、培地と対話で規律の数が二つになるので採らなかった。

### 検査に通らない付与を保存しない

- **保存した培地は後から消さない**: #63 は、問いが変形しても培地を破棄しないと決めているので、規律に反する材料を一度保存すると取り除く手順が無い。
- **保存が `status` を動かす**: 0038 は培地の行が入ったときに `new` を `stocked` へ上げるので、規律に反する付与でも状態が進む。
- **一部だけ保存しない**: 対の片方だけが残ると、残った材料が一方向に閉じる。
- **検査を計算として持つ**: 0035 は「モデルの判断に任せる」を、破られたことを検査できないという理由で採らなかった。

採らなかった案と、それを採らなかった条件。

- **通らない材料だけを除き、残りを保存する**: 一回の付与で材料が付く見込みが上がる。
  対の片方が除かれると残った材料が一方向に閉じるので採らなかった。
- **検査に通らない付与も保存し、違反を示す列を付けて表示する**: 付与の結果が失われない。
  規律に反する材料が画面に並び、`status` も進むので採らなかった。
- **検査を持たず、プロンプトの指示だけに任せる**: 実装が減る。
  破られたことを機械が検出できないので採らなかった。

## 帰結

| 対象 | 変わること |
|---|---|
| AI の送信の契約 | 付与の呼び出しは、検索の指定と検索結果の URL を扱う契約（0043）を使う |
| 培地の表 | 論点をまとめる列と、材料ごとの出典の URL の列が要る。現況は `web/prisma/schema.prisma` が持つ |
| 一回の付与の論点の数 | 上限 3 件と、論点ごとに 2 件以上の組み合わせでは、一回の付与が持てる論点は一つになる |
| 0035 | 4 項の規律は変わらない。帰結「培地の外部材料も同じ形」を、件数・対・出典の検査として実装する。同じ論点の材料の立場が実際に違うかと、断定の形をしていないかは機械で検査せず、人間の判定に残る |
| 0038 | 検査に通らない付与は行を作らないので、`status` を `new` から上げない |
| 0021 | 送信の契約の変更は 0043 が持ち、この ADR は契約を使う側の規律だけを決める |
| 費用 | 付与のたびに web 検索の料金が加わる。決定時点の Anthropic の料金は 1,000 回あたり 10 ドルで、検索結果は入力トークンにも数えられる |
| 組織の設定 | Anthropic の Console で管理者が web 検索を無効にすると、付与は失敗する |
| フェイクモード | 検索結果の URL を含む、決定的な付与の応答が要る |

## 覆る条件

| 起きたこと | 覆る決定 | 要るようになるもの |
|---|---|---|
| 検査に通らず保存されない付与が、常用で繰り返される | 決定 6 | 検査の条件か、付与のプロンプトか、通る材料だけを保存する形の見直し |
| 一回に論点が一つでは、問いへ戻るのに材料が足りないと常用で判定される | 決定 4 | 0035 の件数との揃え方の決め直し（培地と対話で上限を分けるか） |
| 3 件の上限か対立の同梱が、問いを止めていると常用で判定される（0035 の覆る条件と同じ） | 決定 3・4 | 0035 と同時の見直し |
| 検索結果に現れない資料（書籍・論文）を出典にしたくなる | 決定 2 | URL 以外の出典の持ち方と、その検査 |
| 使っているプロバイダで web 検索が使えなくなる | 決定 1 | 外部材料の出所の選び直し |

## この ADR が決めないこと

未決の論点と、覆る条件が書けない事柄は ADR にしない（規約 5）。

| 論点 | 置き場 | 決めない理由 |
|---|---|---|
| 内部交差と異種同型の芽の出所と検査 | #63 | 要求が出たのは外部材料だけである |
| 材料を二体の AI へ渡すか | #63 | 渡さないと決めたが、覆る条件が「渡したくなったら」以上に書けない |
| 検索の回数と出力の上限の値 | コードの定数 | 値は決定の本体にしない（規約 7）。上限を持つこと自体は 0049 決定 3 が持つ |
