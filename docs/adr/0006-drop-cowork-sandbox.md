# 0006. Cowork サンドボックスを副環境として扱う前提を落とす

- **状態**: 採用
- **決定日**: 2026-08-15
- **関係する ADR**: 0003

## 文脈

`HARNESS.md` は主環境（Claude Code / macOS）と副環境（Cowork サンドボックス / Linux）の非対称を表で持ち、ハーネスは「どちらでも `pnpm check` が同じ意味を持つ」ことだけを保証していた。
この前提は Cowork でプランを作っていた時期のものである。

## 決定

副環境として扱う前提を落とす。
`CLAUDE.md` / `ROADMAP.md` / `HARNESS.md` から該当記述を削除した。

落とした表を、経緯として原文のまま残す。

```
| | Claude Code（主） | Cowork サンドボックス（副） |
|--|--|--|
| OS / 制限 | macOS・制限なし | Linux・コマンド 45 秒制限 |
| ネットワーク | 自由（実キー可） | 許可リスト制（Claude API 不可） |
| ビルド | リポジトリ内で可 | FUSE が unlink 拒否 → `/tmp` にコピーして実行 |
| node_modules | macOS ネイティブ | Linux ネイティブ（**相互流用不可**） |

サンドボックスで作業した後は macOS 側で `rm -rf node_modules && pnpm install`。
この非対称は消せないので、ハーネスは「どちらでも `pnpm check` が
同じ意味を持つ」ことだけを保証する。
```

## 理由

ローカルに環境を作れること自体が Claude Code の存在意義である以上、あの制約はもう足場の説明になっていないためである。
実装が Claude Code のローカルで回るようになった時点で、副環境は使われない。

**表を残したまま「いま失効している」と注記する案を採らなかった条件**: 記述が残っている限り、冷えたセッションが制約を前提に設計を曲げる余地が残ること。
実際、`node:sqlite` によるネイティブ依存ゼロという旧方針は、この制約を根拠の一つにしていた（0003）。
注記は読まれる保証が無いので、根拠ごと落とす側へ倒した。

## 帰結

- `CLAUDE.md` / `ROADMAP.md` / `HARNESS.md` から環境差異の記述が消えた
- 同日の永続化の転換（0003）から、旧方針の根拠の一つが外れた
- ハーネスが保証する対象が単一環境になった

## 覆る条件

- **ビルドやネイティブ依存の非対称が再び戻ってきたら**。
  そのときは表の形（何が非対称で、何を保証するか）をそのまま使い、新しい環境の非対称で書き直す。
  なお `CLAUDE.md` が持つ「リモートの縮退モード」はこれに当たらない——あちらは fermentary が並置されないという文書側の非対称で、ビルドとネイティブ依存の非対称ではない
