# toiito — トイット（Toiito）

問いをポイっと投げ入れて発酵させるコンポスター。
自分の問いと向き合うことを AI が支える Web アプリケーション。

AI はもっぱらスピードアップ——速く答えに到達すること——の文脈で語られる。
この器はその逆方向を試すために作っている。
**スローダウン**のために AI を使い、自分の問いを深め、安易な答え・一般論・暫定解に逃げないための道具にする。

やらないことが、このアプリのアイデンティティである。
AI は答えを与えない。
一般論も暫定的な答えも供給せず、問いの深掘りと、過去に自分が持っていた問いとの接続だけを支える。
掘るのは人間の側。

三つの核がある。

- **二対一の対話** — AI 二体 + 人間一人の鼎談。
  具体へ引き下ろす一体と抽象へ跳ぶ一体を置き、視点の衝突と転位で問いを攪拌する。
  構成の下敷きはポッドキャスト『超相対性理論』
- **キーワードメモ** — 対話中の発話を文字選択してメモを残す。
  メモが付いた箇所は下線で可視化される
- **逆引き** — メモの一覧から、それが生まれた当時のセッションへ戻れる。
  対話は流れて消えるものではなく、堆積して振り返れるもの

なぜ作るかの正は [VISION.md](VISION.md)。

## 現況

開発中。
MVP の縦一本——問い投入 → 二視点 AI との対話 → キーワードメモ → メモからのセッション逆引き——は実装として動く。
ただし**公開 URL は無い**。
アプリ側の実行環境が未定なので、いまは手元の開発サーバーでしか起動しない。

残っているのは作者自身が常用できるかの判定で、それが済むまで機能を足さない。

どの順で何を作るかは [ROADMAP.md](ROADMAP.md)、いま何に着手しているかは GitHub Issues が持つ。

## 技術スタック

Next.js (App Router) + TypeScript。
永続化は Postgres + Prisma で、開発と本番の方言を揃えるためローカルも Postgres を立てる（本番は Neon）。
二体 AI の対話生成は Claude API を Server Actions からのみ叩く。
ツールチェーンは mise + pnpm + Biome、テストは Vitest、E2E は Playwright。

確定事項とそれぞれの禁止則は [ARCHITECTURE.md](ARCHITECTURE.md)「技術スタック（確定事項）」が持つ。

開発の入口——起動・環境変数・判定の口の打ち方——は [web/README.md](web/README.md) と [HARNESS.md](HARNESS.md)。
