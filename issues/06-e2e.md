# Playwright E2E（縦一本の 3 シナリオ）
labels: claude,human,harness

**前提**: #3, #4, #5 ／ **担当**: Claude（実走は macOS 側） ／ **参照**: `HARNESS.md` P1 節

## 目的
縦一本（投入 → 対話 → メモ → 逆引き）をブラウザ実挙動で機械検証する L4 層を設置。
以後の変更の退行検知網になる。

## 作るもの
1. Playwright 導入（`@playwright/test`）。`web/e2e/` にスペック:
   - **シナリオ 1**: 問い投入 → 発話 → フェイク応答二体が `ai_a → ai_b` の順で表示
     （`fakeResponse` のペルソナ行をアサート）
   - **シナリオ 2**: 発話本文を選択 → メモ作成 → アンダーライン出現
     （選択は `page.evaluate` で Range を組む）
   - **シナリオ 3**: `/memos` に現れる → リンクで対話画面の該当メッセージへ着地
2. `webServer` 設定で `TOIITO_FAKE_AI=1` + テスト専用 `TOIITO_DB_PATH`（毎回捨てる）。
   投入は #3 の `pnpm seed` を使う
3. スクリプト整理: `pnpm e2e`（Playwright 単体）と `pnpm check:full`（check + e2e）。
   **`pnpm check` は今の速さのまま**（心拍を遅くしない）
4. `HARNESS.md` の P1 節を実装済みに更新

## 環境の注意
Playwright のブラウザ実行は Cowork サンドボックスでは不可能性が高い。
Claude はスペックとシードを書き切り、**実走は macOS / 別 PC 側**。
初回は `pnpm exec playwright install chromium` が必要。
