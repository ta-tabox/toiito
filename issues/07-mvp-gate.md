# MVP 到達判定・台帳更新・常用開始
labels: human,claude,milestone

**前提**: #1〜#6 ／ **担当**: 人間主導 + Claude ／ **参照**: `ROADMAP.md`（MVP 完了条件）, `CLAUDE.md`

## 目的
完了条件「MVP が動き、自分の問いで実際に常用できている」の前半を締め、後半を開始する。

## 作業
1. **[人間]** 実キーで自分の本物の問いを投入し、対話 → メモ → 逆引きを実運用で一巡
2. **[人間]** 以下の閾値を観測する（ROADMAP.md の提案値。調整可）:
   - 常用開始から 2 週間で、本物の問いを **3 件以上**投入した
   - 各問いで **3 往復以上**の対話が成立した
   - メモが合計 **10 件以上**堆積した
   - うち **1 件以上**を、後日 `/memos` から実際に逆引きして辿り直した
3. **[Claude]** fermentary `ATLAS.md`（terrarium 節）の toiito 行を MVP 到達へ更新
4. **[Claude]** `NEXT.md` を整理し、常用フェーズの記述へ切り替える
5. 常用中に出た違和感・問いは膜の一行判定で振り分け
   （アプリ改善ネタ → issue、概念的な学び → fermentary の inbox/questions）

## 満たせなかった場合
足りないのは実装ではなく設計。その旨を `PLAN-rationale.md` に記録し、
問いを fermentary へ搬送してから、次に何を作るかを決め直す。**闇雲に機能を足さない**。

## 完了条件（機械判定）
- `ATLAS.md` の toiito 行が更新済み

## 人間の判定（別トラック）
上記 4 閾値の充足。これがこの issue の実質。
