# 開発用シードスクリプト（`pnpm seed`）
labels: claude,tooling

**前提**: #1 ／ **担当**: Claude ／ **参照**: `HARNESS.md`（P1 節）

## 目的
フェイクモードで UI を手触り確認するための土台。#4 / #5 の手動確認と #6 の E2E が
これに乗る。**旧プランでは E2E と同梱だったが、UI 実装より前に置くほど得**なので
前倒しした。

## 作るもの
- `web/scripts/seed.ts`
  - 問い 2〜3 件、各に対話（人間 + ai_a + ai_b の数往復）とメモ数件
  - **repo 関数だけで書く（生 SQL 禁止）** — スキーマ変更に自動で追従させるため
  - `TOIITO_DB_PATH` を尊重し、任意の DB へ投入できる
  - 冪等でなくてよいが、投入先が既存 DB のとき警告を出す
- `package.json` に `pnpm seed` を登録

## 触らないもの
アプリ本体のコード。

## 完了条件（機械判定）
- `pnpm check` 緑
- 一時 DB パスを指定した `pnpm seed` が成功し、投入後に `listMemosWithContext()` が
  0 件でないことを確認するテスト（またはスモークスクリプト）が通る
